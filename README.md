## 📚 What I'm Learning

### 1. C++ Fundamentals
- Variables and data types
- Input and output (`cin`, `cout`)
- Operators and expressions
- Conditional statements (`if`, `else`, `switch`)
- Loops (`for`, `while`, `do-while`)
- Functions and parameters
- Basic strings and arrays

### 2. Object-Oriented Programming (OOP)

- **Classes and Objects** — Organizing code around objects.
- **Attributes and Methods** — Defining an object's data and behavior.
- **Access Specifiers** — Understanding `public`, `private`, and `protected`.
- **Constructors** — Initializing objects.
- **Encapsulation** — Controlling access to data.
- **Inheritance** — Learning how classes can derive from other classes.
- **Abstraction** — Hiding implementation details behind interfaces.
- **Polymorphism** — Understanding how one interface can support different implementations.

## 💻 Running the Code

You'll need a C++ compiler, such as GCC, and Git installed on your system.

### 1. Clone the repository

```bash
git clone https://github.com/ArGiT69/CPP-LEARNING.git
cd CPP-LEARNING
```

### 2. Compile a C++ file

Replace `main.cpp` with the name of the source file you want to run.

```bash
g++ main.cpp -o main
```

### 3. Run the program

On Windows:

```powershell
.\main.exe
```

On Linux or macOS:

```bash
./main
```

**Note:** Some examples may require compiling their own source files individually.
